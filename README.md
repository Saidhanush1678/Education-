# VIJAY Educational Services - Registration & Faculty Portal

A Flask web application matching the supplied VIJAY Educational Services logo/colors.

## Features

- Home page styled around the supplied logo.
- Candidate/student registration form.
- Formal photo upload.
- Automatic registration number such as `VJES000001`.
- Automatic PDF registration form.
- Automatic QR code.
- QR scan opens a public verification page.
- Public page displays registration details and PDF download.
- Faculty joining/application form.
- Faculty photo and CV upload.
- Automatic Excel workbook with:
  - `Registrations` sheet
  - `Faculty` sheet
  - `Instructions` sheet
- Admin login/dashboard.
- Admin can download the Excel workbook, registration PDFs and faculty CVs.
- SQLite database for persistent records.

## 1. Install Python

Recommended Python 3.11+.

## 2. Open the project

```text
cd VIJAY_Educational_Services
```

## 3. Create virtual environment

Windows:

```text
python -m venv venv
venv\Scripts\activate
```

## 4. Install packages

```text
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

If `pip` itself gives a Windows launcher error, use:

```text
python -m pip install -r requirements.txt
```

instead of `pip install`.

## 5. Run

```text
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

For another computer on the same Wi-Fi/LAN, find your IPv4 address with:

```text
ipconfig
```

Then open:

```text
http://YOUR-IP:5000
```

Example:

```text
http://192.168.1.10:5000
```

## Admin

Default local development login:

```text
Username: admin
Password: admin123
```

Change credentials before deployment.

Windows CMD example:

```text
set ADMIN_USERNAME=youradmin
set ADMIN_PASSWORD=yourstrongpassword
set SECRET_KEY=your-long-random-secret
python app.py
```

## Data storage

- SQLite: `data/vijay.db`
- Excel: `data/VIJAY_Registration_Data.xlsx`
- Registration PDFs: `data/`
- Photos: `static/uploads/photos/`
- Faculty CVs: `static/uploads/cv/`
- QR codes: `static/qrcodes/`

## Important production notes

This is a complete local/initial deployment project. For public internet deployment, add HTTPS, CSRF protection, stronger authentication, password hashing, rate limiting, cloud/private document storage, and a production WSGI server.

The QR code contains the public URL generated by Flask. Therefore, when deploying to a real domain, set the application behind that domain so generated QR codes point to the real public website.
